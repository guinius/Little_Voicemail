Install the certificate

About this certificate

This device signs its own HTTPS certificate using its own private certificate authority (CA) — one made just for this box, not shared with any other Little Voicemail device. Your browser doesn't know about it yet, which is why it shows a warning the first time you connect, even though the connection is already encrypted.

Installing this device's own certificate once on each phone, tablet or computer that opens this page removes that warning for good on every future visit — the padlock shows fully trusted, exactly like any other secure website.

Download the certificate

This file only lets your browser recognise this device's identity. It cannot be used to access anything, and installing it does not give this box - or anyone else - any new access to your phone or computer.

iPhone or iPad

  1. Tap "Download the certificate" above. Safari will say a profile was downloaded.
  2. Go to Settings → General → VPN & Device Management, tap the downloaded profile, then Install (twice, entering your passcode if asked).
  3. One extra step iOS doesn't do on its own: go to Settings → General → About → Certificate Trust Settings and turn on full trust for "Little Voicemail Local CA". Skipping this step leaves the warning in place.

Android

  1. Tap "Download the certificate" above.
  2. Go to Settings → Security (on some phones, Settings → Security → Encryption & credentials) and choose Install a certificate → CA certificate.
  3. Pick the downloaded file and confirm. Some versions of Android show a permanent notification that "a certificate authority is installed" whenever a manually-added one is present — that's expected, not a sign of a problem.

Windows

  1. Download the certificate, then double-click the downloaded file.
  2. Choose Install Certificate, then Local Machine (or Current User), then Place all certificates in the following store and pick Trusted Root Certification Authorities.
  3. Finish, and accept the security prompt.

Mac

  1. Download the certificate. It opens automatically in Keychain Access, in the "login" keychain.
  2. Find "Little Voicemail Local CA" in the list, double-click it, expand Trust, and set "When using this certificate" to Always Trust.
  3. Close the window and enter your password to confirm.

Safari and Chrome both use this system trust store, so one install covers both.

Prefer not to bother?

None of this is required. The connection to this device is already encrypted without it — installing the certificate only silences the one-time browser warning, since it isn't from an authority your browser already trusts. Accepting that warning once per device works just as well if you'd rather skip these steps.
