Link a Signal account

      

        Little Voicemail joins an existing Signal account as a companion device, the
        same way Signal Desktop does. Everything sent to that account arrives here.
      

      

        Use a number the child is not otherwise using. A cheap PAYG SIM,
        or a free number from a service that can receive SMS, keeps the child's box
        separate from your own Signal account. Register the number in the Signal app on
        a phone first.

        Open Signal and link this device
        

          Tap the button. Signal opens and asks whether to link this device — say yes.
          You can do this on the same phone you are reading this page on.
        

        

          Tap the button and Signal will tell you that linking has to start from
          Settings → Linked devices. Go there, choose
          Link New Device, and scan the QR code below
          from a second screen — a laptop, tablet or another phone
          showing this page. Signal on iPhone requires a camera scan and cannot link to
          itself.
        

        

          This button only works on a phone with Signal installed. On a computer, show the
          QR code below and scan it with Signal on the phone that owns the number.

    Once linking succeeds, tap a button on the
    Status page to give it a contact. If linking keeps

    network comes up.

Factory reset

    

      Wipes contacts, quiet times, the ringtone choice, the parent password,
      the linked Signal account and the saved WiFi network, then reboots
      straight into first-run setup — the same state the box was in
      the day it was flashed. The same thing happens if buttons 1 and 2 are
      held together on the device itself for 10 seconds. There is
      no undo.
